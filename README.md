# 🎙️ 録音部 スクリプト管理（本人版）

映画・映像制作の**録音部**向けに、現場でテイクごとの記録（スクリプト）を付けるためのWebアプリです。記録したテイクは Google Apps Script（GAS）経由で Google スプレッドシートに保存されます。

- **記録アプリ**: https://thunder923.github.io/-sound-script-to/
- **管理ビューア**: https://thunder923.github.io/-sound-script-to/viewer.html

これは運用者本人の環境向けの**本人版**です（接続先のGASが初期設定済み）。他の人が自分の環境で使うための共有版は [sound-script-share](https://github.com/thunder923/sound-script-share) を参照してください。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | 記録アプリ（単一HTML。テイクの入力・一時保存・一括送信） |
| `viewer.html` | 管理ビューア（単一HTML。保存済み記録の閲覧・検索・編集・CSV書き出し） |

## 使い方

### 初期設定

1. 記録アプリ左上の「⚙️設定」を開く
2. 保存先の Googleドライブ フォルダ（フォルダ名とフォルダURL）を保存する
3. GAS Webアプリ URL は本人版では設定済み（変更も可能）

### テイクを記録する（記録アプリ）

1. 作品名・日付・ロケ地・シーンの柱・ロール・シーン・カット・テイク・カメラ情報・カメラ クリップ名・レコーダー ファイル番号・評価（OK / KEEP / NG）・備考（ノイズ・セリフかぶり等）・マイク / チャンネル（Ch1〜Ch8）を入力する
2. 「テイクを記録（アプリ内に保存）」を押すと、記録がアプリ内に貯まる（その場で修正・削除もできる）
3. 溜まったら「スプレッドシートへ一括送信 🚀」を押して、まとめてスプレッドシートへ送る

### 保存済みを見る・直す（管理ビューア）

記録アプリの「📊 管理」から開きます（ビューアから記録アプリへも戻れます）。

- 表示の切り替え: **📁 作品ごと / 📅 日付ごと / 🎬 S#ごと**
- 作品フィルタとキーワード検索（備考・ファイルNo・ロケ地・柱・カメラなど）
- 評価フィルタ（OK / KEEP / NG）と、評価ごとの件数表示
- 評価・備考はその場で編集でき、スプレッドシートへ反映される（備考のタグ部分は自動で維持されます）
- **CSV書き出し**対応
- 設定（GAS URL・保存先フォルダ）は記録アプリと共通。同じ端末・同じブラウザなら、記録アプリの設定がそのまま読み込まれます
- 「まずサンプルデータで表示を確認する」から、実データなしで表示だけ試すこともできます

## データの保存先

- 一括送信すると、指定した Googleドライブ フォルダ内に **作品名 = スプレッドシート** が自動作成・更新され、その中の **日付 = シート** にテイクが1行ずつ記録されます
- シートの列: 日付 / ロール / シーン / カット / テイク / ファイルNo / 評価 / 備考（ロケ地・柱・カメラ・クリップ・マイク情報は備考内のタグとして保持され、ビューアでは項目として表示されます）
- 未送信の記録と設定は、ブラウザの localStorage に保存されます

## 注意事項

- スプレッドシートへの送信・読み込みには、GAS のウェブアプリ デプロイ（アクセスできるユーザー: 全員）が必要です
- 管理ビューアで読み込むには、GAS が読み取り対応版（v2）になっている必要があります。古いGASのままだと読み込めません（記録アプリの送信はそのまま使えます）。貼り替え手順はビューア内の「🔧 うまく読み込めないとき」、GASコード自体は記録アプリの「📖 使い方」タブからコピーできます
- 未送信のテイクはその端末・そのブラウザの中だけにあります。送信する前にブラウザのデータを消すと消えてしまうので注意してください
